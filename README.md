# enerlytik — Mac CI scaffold

Minimal repo whose **only** purpose is to build the macOS Intel DMG via
GitHub Actions. Clean snapshot — no DuckDB telemetry, no historical
training scripts, no archived experiments.

## How to build

1. **Settings → Actions → General** → enable "Allow all actions and reusable workflows"
2. Add the 3 Groq keys as repo secrets (Settings → Secrets and variables → Actions):
   - `GROQ_KEY_1`, `GROQ_KEY_2`, `GROQ_KEY_3`
3. **Actions tab → tauri-mac-build → Run workflow** → branch `dev-v2.0` → Run

Build runs on `macos-13` (Intel) targeting `x86_64-apple-darwin` for a
MacBook Air 2020 (Sonoma 14.x). Cold cache: 60–90 min. Output: an
unsigned `.dmg` artifact.

See `tauri_bundle/enerlytik-app/MAC_BUILD_GUIDE.md` for the end-to-end
walkthrough (install on Mac, troubleshooting, etc.).
